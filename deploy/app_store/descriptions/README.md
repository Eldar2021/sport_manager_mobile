# Descriptions

App Store Connect'in Version sayfasındaki tüm metin alanları. **Her dil için ayrı dosya.** Apple bu metinleri inceler — yanıltıcı içerik, marka adı çakışması veya rakip uygulamadan kopya reddi tetikler.

## Limitler

| Alan | Limit | Re-review gerekir mi? |
|------|-------|-----------------------|
| App Name | 30 karakter | Evet (yeni sürüm gerekir) |
| Subtitle | 30 karakter | Evet |
| Promotional Text | 170 karakter | **Hayır** — anında değişir |
| Description | 4000 karakter | Evet |
| Keywords | 100 karakter (virgüllü) | Evet |
| What's New | 4000 karakter | Evet (her sürümle değişir) |

## Diller
- `en.md` — English (Primary)
- `ru.md` — Russian
- `ky.md` — Kyrgyz
- (gerekirse) `tr.md` — Türkçe (Türkiye pazarı için, uygulama içi TR yok — ileride değerlendir)

## ASO ipuçları
- App Name + Subtitle + Keywords toplam **App Store arama sıralamasının %80'ini** belirler
- Keywords alanında **boşluk yok**, sadece virgül: `venue,table,session,billiard`
- Keywords'te app name'i tekrar etme — Apple otomatik indeksler
- Description sadece **insanlar** içindir, arama indekslemesi YOK
- İlk 3 satır kritik — "more" butonundan önce görünür
